# Security Policy

This portfolio intentionally excludes proprietary source code, credentials, private customer data, internal network details, environment values, and production logs.

## Reporting a concern

Please do not disclose a suspected secret or private detail in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner through the public channels listed in [docs/contact.md](docs/contact.md).

Include the affected file and a concise description. Do not include copied credentials or personal data in the report.

## Scope

Reports about the public websites linked from these case studies should be sent to the appropriate website operator. This repository contains portfolio documentation and screenshots only.
