# Contributing

This repository presents selected production work as evidence-based engineering case studies. It does not accept source-code contributions for the featured products.

## Content standards

- Use only public or explicitly approved material.
- Describe measurable facts precisely and name what was measured.
- Do not add credentials, customer data, private infrastructure details, analytics identifiers, or proprietary source code.
- Do not add technologies, metrics, testimonials, or business outcomes without verification.
- Keep project pages consistent with the established case-study structure.
- Optimize images without making interface text unreadable.

## Proposing a correction

Open an issue with the affected file, the proposed correction, and a public verification source when one exists. Security concerns should follow [SECURITY.md](SECURITY.md).
